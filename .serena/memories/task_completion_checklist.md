# タスク完了時のチェックリスト

## 必須チェック項目

### 1. コード品質
- [ ] `npm run lint` を実行してESLintエラーがないことを確認
- [ ] TypeScriptのコンパイルエラーがないことを確認

### 2. テスト
- [ ] 関連するテストファイルがある場合は `npm test` を実行
- [ ] 新機能を追加した場合はテストファイルも作成

### 3. ビルド確認
- [ ] `npm run build` を実行してビルドエラーがないことを確認

### 4. データベース関連（該当する場合）
- [ ] Prismaスキーマを変更した場合は `npx prisma generate` を実行
- [ ] 新しいマイグレーションが必要な場合は `npx prisma migrate dev` を実行

### 5. 動作確認
- [ ] `npm run dev` で開発サーバーを起動して動作確認
- [ ] ブラウザで実際の動作を確認

## 推奨チェック項目

- [ ] 不要なconsole.logの削除
- [ ] コードのフォーマット確認
- [ ] インポート文の整理
- [ ] 型定義の適切な使用
- [ ] エラーハンドリングの実装
